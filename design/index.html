产品概述

WordWorld 单词世界是一款面向 7-12 岁小学生的英语单词记忆 App：以场景化学习地图组织内容，用五维记忆法（形 → 义 → 音 → 记 → 用）拆解每个单词。视觉主题为「自信游戏风」——饱和靛蓝 + 活力橙、实体感游戏按钮、干净投影，保留大孩子的游戏心气，去掉低龄的幼稚感。

页面清单

  • 启动页 — 品牌标识 + 字母块漂浮加载动画
  • 年级注册 — 形象选择 + 昵称 + 1-6 年级难度适配
  • 场景地图 — 今日目标 / 每日挑战 / 场景节点解锁路径
  • 五维学习 — 单词 orange 的五个维度，含拼读着色
  • 练习游戏 — 超市大冒险：看图选词 + 得分 + 生命值
  • 个人中心 — 等级 XP / 错词本 / 勋章墙 / 艾宾浩斯复习
  • 看图作文 — 图片提示 + 提示词插入 + AI 批改入口

交互特性

  • 注册页头像 / 年级卡片单选，昵称实时字数
  • 五维学习 Tab 切换；选词填空即时判定正误
  • 练习游戏答对加分弹跳、答错抖动扣心、出提示
  • 个人中心开关切换、每日目标 ± 步进
  • 作文页点提示词自动填入并计字数
  • 所有可点元素有按压下沉反馈（实体按钮）

本版改了什么（v1 → v2）

  • 风格黏土拟物 / 幼儿园观感 → 自信游戏风：靛蓝主色 + 活力橙强调，游戏实体按钮（按住下沉），干净柔和投影。
  • 字体Comic Sans / Comic Neue → Baloo 2（标题）+ Nunito（正文），圆润但干练，适合 7+ 阅读习惯。
  • 图标全部 emoji 占位图标 → 统一线性 SVG 图标，描边粗细一致，跨平台渲染稳定。
  • 玩法首页从"进度卡片"升级为游戏地图：场景节点、星星评分、锁定路径、每日挑战。
  • 教学自然拼读语义色原样保留：元音红 / 辅音蓝 / 静音灰，仅微调辅音蓝与新主色一致。
