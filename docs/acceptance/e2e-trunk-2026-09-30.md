# E2E 学习主干验收记录

- **规格**：Issue #1（E2E 学习主干（H5）：注册 → 场景地图 → 五维学习卡 → 学习小结）
- **验收日期**：2026-09-30
- **验收方式**：Playwright 375px(812) + 桌面 1280(800) 自动化走查（脚本 17/17 通过），辅以 vitest 21 用例、pytest 21 用例
- **环境**：H5 dev（uni-app :3002）+ FastAPI（:8000），种子数据 3 场景 / 4 子场景 / 15 词 / 33 条音频

## 六条验收标准

### ① 注册后首页显示真实场景进度 — ✅ 通过

新用户完整路径（启动 → 引导 → 注册昵称+年级 → 首页）全程无占位文本；首页显示 3 个场景节点（我的家 / 我的学校 / 超市购物）与真实进度「已学会 0 / 15 个单词」。token 持久化，刷新后仍为登录态。

### ② 子场景词表显示 15 词及学习状态 — ✅ 通过

三个场景经真实导航（首页场景卡）依次进入：我的家（厨房+客厅）、我的学校（教室）、超市购物（水果区），共 15 词。每词状态徽章含**文字**（新学/学习中/熟悉/掌握）与**形状**（○/◐/☆/★），颜色仅辅助（`getLearningStatusMeta` 渲染段唯一性有测试锁定）。水果区正确显示 5 个水果词（orange/banana/grape/strawberry/peach）。

### ③ 完整走完一个词的五维且音频可播放 — ✅ 通过

学习页按 wordId 加载真实数据：认形（letter_sounds 语义色字母块）、识义（配图+释义）、拼读（音节 or·ange + 分隔音标）、巧记（联想助记）、运用（例句逐句音频）。单词与例句音频点击播放、可重复播放跟读（网络请求断言 + 重播 playing 态断言）。维度前进/后退/点击跳转可用；完词后自动进入下一词。

### ④ 小结页数字来自后端 — ✅ 通过

小结页全部数字取自 `GET /api/v1/learning/stats`：本次学词（today_learned）、五维完成度（dimensions_completed / learned×5）、掌握情况三项、下次复习时间（next_review_at，简化 SM-2：首次完词 +20 分钟）。E2E 将 UI 展示值与 API 响应逐项比对一致。空会话显示空态（奖杯灰化 + 引导 CTA）不崩溃。

### ⑥ 375px 宽度可用 — ✅ 通过

375px 下五个关键页（首页/词表/学习/小结/引导注册）无布局破损、无横向滚动；桌面 1280px 同样通过。

## 专项抽查

- **触控目标与间距**：首页场景节点、词表词卡、学习页步骤/导航/音频按钮、注册页年级卡均 ≥44px；相邻元素（同行水平/同列垂直）间距 ≥8px。注：词表「状态徽章」为信息展示非控件，触控目标为其所在词卡（≥120rpx）。
- **拼读语义色未被风格覆盖**：形维字母着色实测 rgb(255,107,107) 元音红 / rgb(79,70,229) 辅音蓝 / rgb(139,92,246) 字母组合紫，与教学令牌一致（`utils/phonics-colors.ts` 单源）。
- **视觉规范**：按 MASTER **v2 自信游戏风**执行（工单中「Claymorphism」为 v2 修订前旧称）——实体底边按钮、按压下沉不缩放、线性 SVG 图标（tabBar 图标管线 `scripts/gen-tab-icons.mjs`）、`prefers-reduced-motion`。

## 遗留事项

1. **平台行为（非缺陷，已记录）**：uni H5 对同路由不同参数的 hash 直达会复用 keep-alive 实例（onLoad/onShow 均不触发）。真实用户路径（首页 navigateTo）不受影响；深链分享场景如需支持，后续可加 hashchange 监听。
2. **规格外模块**：练习、看图作文、我的页维持静态壳（规格 Out of Scope）。

**六条验收标准全部通过**，E2E 学习主干（注册 → 场景地图 → 词表 → 五维学习卡 → 会话流转 → 学习小结）按规格交付。
